# Simple MA Backtester

A Python script that fetches historical market data via `yfinance`, calculates 50-day and 200-day Simple Moving Averages, and evaluates strategy performance (returns and max drawdown) against a standard Buy & Hold benchmark using `pandas`, `numpy`, and `matplotlib`.

## Features
* Automated market data pipeline using `yfinance`
* Vectorised indicators and signal generation with `numpy`
* Portfolio performance & drawdown calculations
* Visual dashboard output with `matplotlib`
